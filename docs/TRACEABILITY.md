# Capability traceability

This map links each baseline OpenSpec capability to runtime code, regression evidence, and known acceptance gaps. A `PARTIAL` status means the capability has some implementation, but the repository does not yet show evidence for every required runtime path and critical scenario. Do not change a status to `PASS` until the evidence column links to passing regression coverage or a documented live check for the critical scenarios.

Statuses are conservative. This is the initial capability inventory, not a claim that every listed scenario has had a complete code and live-server audit. Review the linked specification and implementation when changing a status.

## Status changes

For each capability promoted to `PASS`, add direct references to the implementation and the tests or live procedure that cover its critical spec scenarios. Keep unimplemented or unverified scenarios listed under remaining work. A passing workspace build alone is not evidence for `PASS`.
