# Integrate grounded legacy quest item use

## Why

Quest item rules can describe a target entry that differs from the objective credit entry. The lane already resolves these catalog facts to shared targeted item-use actions, but it must also confirm that authoritative item-template data agrees with the configured use spell.

## Scope

Add item-template agreement checks before quest item use, retain shared authoritative item-instance validation, shared movement, and quest-credit waiting, and cover the Inoculation case from the old bot.
